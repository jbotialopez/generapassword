Quiero rediseñar completamente la interfaz de esta aplicación web de generación de contraseñas.

Objetivo:
Crear una interfaz moderna, profesional y atractiva, similar a las aplicaciones  actuales.

No modifiques la lógica JavaScript existente salvo que sea necesario para integrar el nuevo diseño.

## Diseño

- Diseño minimalista.
- Apariencia moderna (2026).
- Totalmente responsive.
- Soporte para modo claro y oscuro.
- Utilizar CSS moderno (Flexbox/Grid).
- Animaciones suaves.
- Sombras sutiles.
- Bordes redondeados.
- Espaciado consistente.
- Tipografía moderna (Inter o Poppins).
- Iconos de Lucide Icons o Font Awesome.

## Organización

La página debe tener:

- Encabezado con el nombre de la aplicación.
- Tarjeta principal centrada.
- Contraseña generada en una caja destacada.
- Botón Copiar.
- Botón Generar.
- Indicador visual de fortaleza con colores.
- Longitud mediante un slider.
- Opciones mediante switches modernos:
    - Mayúsculas
    - Minúsculas
    - Números
    - Símbolos
    - Evitar caracteres ambiguos

## UX

- Feedback visual al copiar.
- Animación al generar una contraseña.
- Estados hover y focus.
- Transiciones suaves.
- Accesibilidad.
- Navegación mediante teclado.

## Código

- HTML limpio y semántico.
- CSS organizado.
- JavaScript separado si es posible.
- No eliminar funcionalidades existentes.
- Mantener el código fácilmente mantenible.

## Antes de implementar

1. Analiza la estructura actual.
2. Propón una nueva distribución.
3. Explica las mejoras.
4. Implementa el rediseño completo.
